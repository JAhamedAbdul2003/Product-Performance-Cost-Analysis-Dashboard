# Product-Performance-Cost-Analysis-Dashboard
This dashboard analyzes task volume, production output, and cost efficiency across managers, product types, regions, and time periods. The goal is to identify cost drivers, productivity patterns, and performance gaps using Excel-based analytics and visualization.

📌 Key KPIs

Total Number of Tasks

Total Units Produced

Average Product Cost

Total Cost Incurred

Each KPI is supported with trend indicators and connected to deeper breakdowns for analysis.

📈 Dashboard Insights

Manager Performance:
Clear variation in cost per unit across managers, highlighting efficiency gaps.

Product Cost Analysis:
Furniture and Automobiles show significantly higher unit costs compared to Machinery and Electronics.

Time-Based Trends:
Monthly production shows volatility with noticeable spikes, indicating irregular demand or operational events.

Interactive Analysis:
Slicers for Gender, Region, and Manager allow dynamic filtering and focused insights.
